# Phase 19b QTL coverage and signal audit

This validated WS4 bundle covers the frozen P1+P2 scope: 116 genes, 269
sex/APOE-by-network contexts, and 538 eQTL/sQTL routes. It was generated by
streaming three official, MD5-validated NG00184 fine-mapping archives.

The public QTL sources are exact broad-lineage or bulk-brain fallback data, not
sex/APOE-stratified data. A source-significant QTL signal is therefore an
annotation and downstream gate, not exact-context or AD validation.
